🏋️ MovFit

Aplicação web para explorar, organizar e criar planos de treino personalizados.

Sobre o Projeto:

O MovFit é uma aplicação web desenvolvida com React e Vite, que permite aos utilizadores explorar diferentes planos de treino, consultar exercícios e criar rotinas personalizadas.

O projeto pretende proporcionar uma experiência simples, intuitiva e interativa, ajudando os utilizadores a organizar os seus treinos de acordo com os seus objetivos e preferências.

🎯 Objetivos

Criar uma plataforma interativa de planos de treino.

Facilitar a pesquisa e organização de exercícios.

Permitir a criação de treinos personalizados.

Aplicar os conhecimentos adquiridos em React.

🛠️ Tecnologias Utilizadas

React : como biblioteca principal para a construção da interface; JavaScript : implementação da lógica da aplicação; HTML/JSX : definição da estrutura; CSS : apresentação visual e adaptação a diferentes ecrãs; Vite : criação e execução do projeto; Git e GitHub: gestão e disponibilização do código.

Estrutura de Componentes:

Componente e Descrição a baixo;

Header.jsx Cabeçalho e menu de navegação.

PlanCard.jsx Cartão individual de cada plano de treino.

PlanDetails.jsx Apresentação dos detalhes e exercícios de um plano.

PlanForm.jsx Formulário para criar planos personalizados.

ExerciseCard.jsx Apresentação individual dos exercícios.

Footer.jsx Rodapé da aplicação.

App.jsx Componente principal e gestão da aplicação.

Funcionalidades:

-Visualização de planos de treino predefinidos. -Pesquisa de planos por nome. -Filtragem por categorias. -Consulta de exercícios e informações dos planos. -Adição e remoção de planos favoritos. -Criação de planos de treino personalizados. -Consulta e eliminação dos planos criados. -Interface responsiva e intuitiva.

Conceitos React Aplicados

-Componentização e reutilização de componentes. -Passagem de propriedades através de props. -Gestão de estados com useState. -Renderização de listas com map(). -Filtragem de dados com filter(). -Utilização de key em listas. -Eventos onClick, onChange e onSubmit. -Formulários controlados. -Renderização condicional.

Como Executar o Projeto

Clonar o repositório:
git clone URL_DO_REPOSITORIO

Entrar na pasta do projeto:
cd MovFit

Instalar as dependências:
npm install

Iniciar o servidor de desenvolvimento:
npm run dev

Abrir no navegador:
http://localhost:5173/
